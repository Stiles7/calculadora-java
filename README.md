# 🧮 Calculadora em Java

Projeto desenvolvido durante meus estudos de Java para praticar lógica de programação, Programação Orientada a Objetos e estruturas de controle.

## ✅ Funcionalidades

- [x] Soma
- [x] Subtração
- [x] Multiplicação
- [x] Divisão
- [x] Potência
- [x] Raiz Quadrada
- [x] Histórico de Operações
- [x] Validação de Entradas

## 🛠️ Tecnologias Utilizadas

- Java
- Scanner
- ArrayList
- Math

## 📚 Conceitos Praticados

- Programação Orientada a Objetos (POO)
- Classes e Objetos
- Métodos
- Switch Case
- Estruturas de Repetição (do-while)
- Coleções (ArrayList)
- Tratamento de Erros

## 💻 Exemplo de Uso

```text
======= Calculadora =======

1 - Somar
2 - Subtrair
3 - Multiplicar
4 - Dividir
5 - Potência
6 - Raiz Quadrada

Escolha uma opção:
```

## 🚀 Aprendizados

Durante este projeto pratiquei:

- Organização de código em classes
- Uso de coleções com ArrayList
- Manipulação de entradas com Scanner
- Utilização da classe Math
- Estruturas de decisão e repetição
- Boas práticas de programação em Java
